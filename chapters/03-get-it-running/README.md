# Chapter 3: Get Computer Use running

Do the setup clicks from the chapter first: Computer use on in Claude's Settings, Screen Recording and Accessibility on for Claude in System Settings > Privacy & Security, then Command+Q and reopen. Add your Documents, Downloads and Desktop folders to the connected folders. Leave Cowork on "Ask before acting" (the default). Claude then checks with you before it does anything that matters (chapter 2).

Then paste these into the Cowork chat, one at a time, and watch your screen.

```
Open TextEdit and create a new document. Type "Hello from Claude Computer Use" and save it to my Desktop as "cowork-test.txt"
```

```
Open Safari, go to google.com, search for "weather today," and tell me the current temperature in the chat.
```

```
Open Finder, go to my Downloads folder, and list the 5 most recently downloaded files.
```

It worked if `cowork-test.txt` is on your Desktop with "Hello from Claude Computer Use" inside, and Claude typed the current temperature into the chat. If Claude only describes the steps instead of doing them, check that Computer Use is on. Chapter 3's "Things That Will Go Wrong on Day One" lists what else to try.
