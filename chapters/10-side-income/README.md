# Chapter 10: Sell it, or use it on your job search

The prices below are the book's examples. Set your own, and read [DISCLAIMER.md](../../DISCLAIMER.md) before you quote anyone.

Upwork or Fiverr listing, ready to edit:

```
TITLE: I Will Set Up AI Desktop Automation (Email, Reports, Data)

DESCRIPTION:
I set up Claude Cowork automations that handle your busywork
while you focus on real work.

What you get:
- Email triage system: AI processes your inbox every morning,
  categorizes messages, drafts replies, sends you a 1-page summary
- Weekly data reports: AI reads your spreadsheets and generates
  plain-English analysis with trends and recommendations
- File organization: AI audits and organizes messy folders with
  a written summary of what is where
- Recurring tasks: scheduled automations that run daily/weekly
  without your involvement

Each setup includes: installation, configuration, rule files,
tested prompts, and a 30-minute walkthrough so you understand
how everything works. One month of email support included.

PRICING:
- Basic (email triage only): $500
- Standard (email + data reports + file org): $1,000
- Premium (full workflow suite + 3 months maintenance): $2,000
```
